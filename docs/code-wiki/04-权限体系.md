# 04 权限体系（模块系统与盲审）

> 回到 [Code Wiki 索引](./README.md) | 上一章：[03 配置系统与数据模型](./03-配置系统与数据模型.md)

本文件描述"内核 + 模块 + Hook"的插件化体系，以及以盲审为核心的信息脱敏权限模型。盲审在各模块中的具体实现见 [02 目录结构与模块职责](./02-目录结构与模块职责.md) 的 2.4 节。

## 1. 插件化架构：内核 + 模块 + Hook

### 1.1 与模块组合加载顺序

`module` 键支持逗号分隔，`\sdu_load_module:` 按顺序加载。模块文件命名 `sduthesis-<name>.sty`，包名由 `sduthesis-` + 模块名拼接后 `\RequirePackage`。

### 1.2 六个命名 Hook

| Hook 名称 | 触发时机 | 典型用途 |
|----------|---------|----------|
| `sduthesis/after-setup` | `\SDUSetup` 处理完、begindocument | 配置后初始化 |
| `sduthesis/before-cover` | 封面生成前 | 盲审预处理等 |
| `sduthesis/cover-style` | 封面样式注入 | 封面版式 |
| `sduthesis/frontmatter/begin` | 前言开始 | 空白页眉页脚 |
| `sduthesis/mainmatter/begin` | 正文开始 | 正文页眉页脚切换 |
| `sduthesis/backmatter/begin` | 后记开始 | 参考文献/致谢/附录样式 |

触发方式：内核在对应阶段调用 `\UseHook{sduthesis/xx}`；模块/用户用 `\AddToHook{sduthesis/xx}{...}` 注册。定义见 [dtx L694](file:///workspace/src/sduthesis.dtx#L694-L699)。

### 1.3 组合加载示例

```latex
\SDUSetup{ module = {master, blindreview}, ... }   % 硕士 + 盲审
\SDUSetup{ module = {master}, info = { degree = {博士}, ... } }  % 博士
\SDUSetup{ module = {blindreview} }                % 仅盲审（自动前置本科）
```

## 2. 盲审权限模型（信息安全脱敏）

盲审模式是一个**叠加层**，随 `module` 中的 `blindreview` 启用，用于在送审阶段隐藏作者、学号、导师等敏感信息。

### 2.1 权限控制命令

- `\IfBlindReviewTF{#1}{#2}`：盲审标志条件，为真输出 `#1`，否则输出 `#2`
- `\IfBlindReviewF{#1}`：非盲审才输出 `#1`（用于保护敏感字段）
- 底层由闭包布尔 `\l__sdu_blindreview_bool` 驱动（`\bool_set_true:N`）

### 2.2 脱敏动作

1. **掩码 Getter**：`\GetAuthor` `\GetStudentId` `\GetSupervisor` `\GetCommitteeChair` `\GetCommitteeMembers` → 全部输出 `***`
   - 用 `\renewcommand` 覆盖（非 xparse），使掩码值可被回归测试 `\ASSERT`（内部 `\edef`）直接展开比对。
2. **跳过声明页**：`\renewcommand{\makestatement}{}`（整页不输出）
3. **跳过答辩委员会页**：`\renewcommand{\makecommittee}{}`（整页不输出）
4. **封面字段按需隐藏**：本科/硕士模块以 `\IfBlindReviewF{}` 包裹作者姓名、学号、指导教师等敏感行。

### 2.3 盲审回退策略

单独使用 `module={blindreview}`（无基础模块）时，内核加载器自动前置加载本科模块 `undergraduate`，与书写顺序无关；`{blindreview, master}` 不会重复加载两个基础模块。
